# Lumivox keyword map

This document is the on-page SEO source of truth for the 14 public English and Vietnamese URLs. It maps one primary search intent to each page so future copy changes do not make multiple URLs compete for the same query.

## Operating rules

- Write for the visitor first. Use the vocabulary below only where it describes the page naturally.
- Home owns the broad product category. Features owns capability evaluation. Research owns task-delay and study-behavior evidence.
- About, Privacy, Terms, and Contact are primarily branded or navigational pages; they do not need generic commercial targets.
- Do not add `meta keywords`, invented search volumes, repeated exact-match phrases, or thin exact-match landing pages.
- Keep English and Vietnamese copy native to each language. Vietnamese terms are not literal translations of English queries.
- Revisit this map when Search Console provides real query and impression data.

## Home

### English

- **URL:** `/en`
- **Search intent:** Product discovery
- **Primary query:** AI study planner
- **Secondary queries:** AI study planner for students; student productivity app; study planner with focus timer
- **Page purpose:** Define the Lumivox product category, explain the complete workflow, establish evidence and trust, and move suitable visitors toward feature evaluation or account creation.
- **Title:** `AI Study Planner for Students | Lumivox`
- **H1:** `An AI study planner for calmer, more measurable learning.`
- **Meta description:** `Plan tasks, run focus sessions, understand study habits, and get AI-assisted recommendations with Lumivox, an AI study planner for students.`
- **Internal links in:** Global logo and Home navigation; footer links from all public pages.
- **Internal links out:** Features, Research, Privacy & Data Use, About, sign up, and log in.
- **Notes:** Keep `Study with calm intelligence` as the brand phrase rather than the H1. Use the category phrase once in the hero and support it with concrete capabilities and real evidence.
- **Do not compete with:** `/en/features` for detailed capability evaluation or `/en/research` for model methodology.

## Validation checklist

- Every public URL has one unique title, H1, and meta description in its own language.
- Each page has exactly one H1.
- Canonical, `hreflang` (`en`, `vi`, and `x-default`), and sitemap URLs remain aligned.
- Contextual link text describes its destination without keyword stuffing.
- Image alt text describes the visible product state and does not act as a keyword list.
- No `keywords` metadata field or extra exact-match landing page is introduced.
