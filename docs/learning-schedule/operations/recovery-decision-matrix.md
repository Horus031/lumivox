# Learning Schedule recovery decision matrix

The operator CLI is read-only. Mutations require the existing trusted worker or server-side RPC boundary with approved restricted access. Capture aggregate before and after snapshots and the incident reference. Keep message IDs, handoff tokens, fingerprints, addresses and credentials out of shared reports.

| Persisted evidence                                                  | Decision                                                                                                                                                                                                                                    | Validation                                                                                                                                |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Active lease or uncertain lease state                               | Leave the attempt alone. Wait for a valid terminal state or confirmed expiry.                                                                                                                                                               | Compare lease age and durable state on the next poll.                                                                                     |
| Expired lease with no durable handoff                               | Run the existing service-role `ls_notification_reconcile_expired_leases` in bounded batches of 1–25 through the trusted worker or approved restricted DB path. The reconciler checks owner locks, lease expiry, relevance and claim budget. | An eligible job returns to pending without a delivery or submission. Expired, suppressed and exhausted jobs stay terminal as appropriate. |
| Expired lease after durable handoff, or uncertain provider response | Hold. The reconciler moves a submitting attempt to uncertain and removes the lease. It never submits another email.                                                                                                                         | No new provider calls after re-enable. Preserve the original payload and attempt.                                                         |
| Trusted evidence confirms acceptance                                | Use `ls_notification_record_resend_outcome` only with the original durable delivery facts and a trusted message ID. An authentic, matching webhook can also converge through the existing correlation path.                                 | Original delivery becomes accepted or advances through the webhook lifecycle. No extra provider request.                                  |
| Confirmed, allowlisted HTTP 429 rate limit                          | Let `ls_notification_record_resend_rate_limit` and normal worker polling apply the persisted backoff, relevance and claim budget.                                                                                                           | Original payload and key remain unchanged. No immediate worker retry.                                                                     |
| Quota, payload mismatch or conflicting provider evidence            | Quota and mismatch stay terminal for automatic sending. Conflicting or missing evidence stays on hold and is escalated.                                                                                                                     | Verify no repeated submissions.                                                                                                           |

Do not run a batch reconcile while the target environment or incident scope is unknown. The reconciler is global within the target project and can update multiple owners. Do not replace it with direct delivery/job updates or an arbitrary-ID operator command.
